# SchoolSubstitutions

Приложение для автоматизации составления школьного расписания, управления учебными планами и учета замен преподавателей.

## Требования

- .NET 8.0 или выше
- Windows 10/11

## Установка и запуск

1. Установить .NET 8.0 или выше.
2. Скопировать `SchoolSubstitutions.exe` в нужную папку.
3. Запустить программу двойным щелчком мыши.

## Основные возможности

### Настройки

- Импорт учителей
- Импорт кабинетов
- Импорт предметов
- Изменение настроек расписания
- Удаление всех данных

### Учебные планы

- Добавление учебного плана
- Изменение учебного плана
- Удаление учебного плана

### Кабинеты

- Добавление кабинетов
- Изменение кабинетов
- Удаление кабинетов

### Предметы

- Добавление предметов
- Удаление предметов

### Классы

- Добавление классов
- Удаление классов
- Добавление подгрупп
- Удаление подгрупп

### Учителя

- Добавление учителей
- Изменение учителей
- Удаление учителей

### Группы сотрудников

- Добавление групп сотрудников
- Удаление групп сотрудников

### Расписание

- Добавление уроков
- Изменение уроков
- Удаление уроков
- Добавление замен
- Изменение замен
- Удаление замен
- Удаление расписания
- Экспорт расписания
- Экспорт замен

### Отчёты

- Формирование отчётов
- Экспорт отчётов

## Цветовая индикация

| Цвет ячейки | Значение |
|-------------|-----------|
| Жёлтый | Замена |
| Красный | Конфликтующие замены |
| Красный | Замена конфликтует с уроком |
| Светло-красный | Урок конфликтует с заменой |

## Хранение данных

Для хранения данных используется база данных SQLite.

Файл базы данных:

```text
school.db
```

## Возможные проблемы

### Программа не запускается

Проверьте установленную версию .NET.

### Данные не сохраняются

Проверьте права на запись в папку, в которой находится файл базы данных.

### База данных повреждена

Удалите файл:

```text
school.db
```

При следующем запуске будет автоматически создана новая база данных.

## Сообщения программы

| Сообщение | Причина |
|-----------|----------|
| Нет уроков | Попытка экспорта расписания без уроков |
| На этот день замен нет | Попытка экспорта замен без замен |
| Файл уже открыт. Закройте Word и попробуйте снова | Файл замен или отчёта открыт |
| Файл уже открыт. Закройте Excel и попробуйте снова | Файл расписания открыт |
| Файл открыт. Закройте Excel и попробуйте снова | Импортируемый файл открыт |
| Отсутствуют введённые значения | Не заполнены обязательные поля |

Сообщения носят информативный характер и не приводят к аварийному завершению работы программы.
