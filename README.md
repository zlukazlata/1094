# SchoolSubstitutions

Приложение для формирования отчётов по учебной деятельности(расписание, замены, учебные планы).

## Требования

- .NET 8.0 или выше
- Windows 10/11

## Запуск

1. Установить .NET 8.0 или выше.
2. Перейти в папку build.
3. Запустить программу SchoolSubstitutions.exe двойным щелчком мыши.

## Импорт данных

Перед началом работы рекомендуется импортировать исходные данные через раздел **Настройки**.

### Учителя

Кнопка: **Импорт учителей**

Файл:

```text
Учителя_по_группам_сотрудников.xlsx
```

### Кабинеты

Кнопка: **Импорт кабинетов**

Файл:

```text
Расписание_по_кабинетам.xlsx
```

### Предметы

Кнопка: **Импорт предметов**

Файлы:

```text
1-4-класс-название предметов.xlsx
5-класс-название предметов.xlsx
6-7-класс-название предметов.xlsx
8-9-класс-название предметов.xlsx
10-11-класс-название предметов.xlsx
```

### Настройки

- Импорт учителей
- Импорт кабинетов
- Импорт предметов
- Изменение настроек расписания
- Удаление всех данных

### Учебные планы

- Добавление учебного плана
- Изменение учебного плана
- Удаление учебного плана

### Кабинеты

- Добавление кабинетов
- Изменение кабинетов
- Удаление кабинетов

### Предметы

- Добавление предметов
- Удаление предметов

### Классы

- Добавление классов
- Удаление классов
- Добавление подгрупп
- Удаление подгрупп

### Учителя

- Добавление учителей
- Изменение учителей
- Удаление учителей

### Группы сотрудников

- Добавление групп сотрудников
- Удаление групп сотрудников

- Добавление уроков
- Изменение уроков
- Удаление уроков

- Изменение замен
- Удаление замен
- Удаление расписания

- Экспорт замен

### Отчёты

- Формирование отчётов
- Экспорт отчётов

## Цветовая индикация

| Цвет ячейки | Значение |
|-------------|-----------|
| Жёлтый | Замена |
| Красный | Конфликтующие замены |
| Красный | Замена конфликтует с уроком |
| Светло-красный | Урок конфликтует с заменой |

## Хранение данных

Для хранения данных используется база данных SQLite.

Файл базы данных:

```text
school.db
```

## Возможные проблемы

### Программа не запускается

Проверьте установленную версию .NET.

### Данные не сохраняются

Проверьте права на запись в папку, в которой находится файл базы данных.

### База данных повреждена

Удалите файл:

```text
school.db
```

При следующем запуске будет автоматически создана новая база данных.

## Сообщения программы

| Сообщение | Причина |
|-----------|----------|
| Нет уроков | Попытка экспорта расписания без уроков |
| На этот день замен нет | Попытка экспорта замен без замен |
| Файл уже открыт. Закройте Word и попробуйте снова | Файл замен или отчёта открыт |
| Файл уже открыт. Закройте Excel и попробуйте снова | Файл расписания открыт |
| Файл открыт. Закройте Excel и попробуйте снова | Импортируемый файл открыт |
| Отсутствуют введённые значения | Не заполнены обязательные поля |

Сообщения носят информативный характер и не приводят к аварийному завершению работы программы.
